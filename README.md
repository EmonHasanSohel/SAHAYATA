# SAHAYATA Project

## Project Description
SAHAYATA is a comprehensive disaster management and relief distribution platform. It connects victims in need with donators and volunteers, while admins and managers monitor the entire process to ensure efficient delivery of relief materials.

## Project Structure
* **SahayataPortal.txt**: Contains the core module structures and pseudocode for the system.
* **PROJECT_FEATURES.md**: Lists all the implemented features and capabilities of the platform.
* **CHANGELOG.md**: Tracks the version history, updates, and feature additions.
* **README.md**: Provides the project overview, structure, and team information.
